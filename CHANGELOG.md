# Changelog

Version history for the STRIDE threat-model toolchain.

Moved out of the prompt and skill file headers on 2026-07-29. The in-file history had grown to
roughly 5,000 tokens between the two files -- provenance that every run paid for in context and no
run used. `git log` is the authoritative record and carries far more detail, including the field
observation behind each change; this file preserves the header summaries verbatim so nothing is
lost to anyone reading without git.
